The upstream provides mobile-focused automation investment and flakiness checklists. This package covers the installed runner across domains, independent oracles, correct real/fake boundaries and owned fixtures. It avoids fixed test ratios, automatic age-based deletion or always mocking real concurrency when that is the property being tested. It does not reproduce platform runner examples or claim a CI result from a local fixture.

No matched provider/task trial or superiority claim. Native parsing and discovery are compatibility checks, not proof of device behavior, architectural fitness, automation efficacy or learning improvement. Behavioral acceptance references contain future trial inputs, not executed results.
