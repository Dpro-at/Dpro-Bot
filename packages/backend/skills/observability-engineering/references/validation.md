# Validation and acceptance evidence

## Select a boundary

A source-only task can finish with a concrete signal contract,query,rule or configuration candidate and relevant available static/fixture checks. It need not activate monitoring. A live diagnosis requires scoped backend/tenant/time identity and actual observations. A deployment or notification test requires additional applicable authority,including installation,service,cost or messaging constraints.

Choose the smallest check that resolves the uncertainty. Use current installed validators and actual platform documentation;do not install a stack simply to claim a check ran. Preserve exit status,versions and sanitized outputs. If a tool or target is unavailable,label the check unexecuted and state the precise prerequisite.

## Distinct evidence layers

- Parsing/schema:the candidate is accepted by the selected parser/schema/version.
- Rule/query fixture:declared inputs produce the tested expression/transition behavior under that tool.
- Collection:the intended producer emits and its configured collector receives the scoped signal.
- Delivery/storage:the intended tenant/backend accepts and exposes the expected signal within the observed delay.
- Query/panel:the expression and variables return the intended unit/population and render correctly for the audience.
- Alert path:condition evaluation and routing lead to the intended notification channel;provider acceptance and human receipt remain separate observations.
- Operational usefulness:an authorized operator can answer the intended question or perform the runbook with the available evidence.

No earlier layer proves every later one. Fixtures do not reproduce production scale or privacy coverage. A package's native host discovery says nothing about real telemetry delivery.

## Review output

For findings include scope,evidence location,consequence,proposed remedy,owner and uncertainty. State where you searched before calling a resource absent,including central/shared ownership. Avoid boilerplate severity or mandatory tools unrelated to the actual impact. Record what changed,what ran,what remains unobserved and any costs/data retention effects. Keep live logs/traces and personal data out of reusable exports.
