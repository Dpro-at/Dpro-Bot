# Design, coverage and tradeoffs

The selected upstream account-plan, lead-triage, CRM hygiene, outreach and forecast entrypoints were reviewed as workflow references. This package independently expresses shared evidence and execution rules plus four full professional modes. It does not reproduce their text, connector-specific commands or templates.

Upstream strengths include live CRM grounding, file fallback, contextual source links and explicit proposal/application separation. This package adds distinct customer-value/renewal continuity, fit-versus-intent-versus-contact-permission, population reconciliation, currency/cohort semantics and uncertain-write handling. It avoids treating illustrative priority proportions, staleness thresholds, copy lengths or sales-cycle estimates as universal policy.

The tradeoff is less turnkey vendor-specific execution: this package does not ship CRM adapters, a scoring model, enrichment service, campaign engine or sending integration. Current workspace tools and actual host permissions remain necessary. No matched selling, conversion or CRM behavior comparison has been run; broader written coverage does not establish superior results. All future acceptance briefs remain unexecuted.
