# Design notes and comparison scope

Reviewed source: [SkillMedev/skills](https://github.com/SkillMedev/skills/tree/bea4ea5d81f5003e01447855df0ca0002dfed60c/skills/deep-research).

Pinned source commit: `bea4ea5d81f5003e01447855df0ca0002dfed60c`. Reviewed on2026-10-25.

The reviewed skill emphasizes independent evidence, structured synthesis and visible gaps. This package uses its own wording and adds an explicit claim ledger, source-origin accounting, scope/date reconciliation and an optional mechanical audit. It also supports a bounded single-fact mode instead of requiring a full investigation for every use.

The package instructions, templates and helper code are original project work. No upstream prompt or executable helper is bundled. The project license applies to our files; the referenced repository retains its own terms.

This is a design/coverage comparison, not a claim that every model performs better with this package. Discovery, helper execution and observed task quality are separate validation levels.
