The MCP builder upstream offers concrete server/SDK implementation and evaluation guidance. This package covers a different, broader application boundary: conversation identity, user credentials, retrieval and memory ownership, tool authority and layered evaluation. It does not reproduce the SDK examples or claim to be a complete MCP implementation guide. A host discovering a skill does not prove model/tool reliability.

No matched model-task trial or quality superiority result is claimed. Acceptance briefs are unexecuted inputs. Parsing, resource integrity and native discovery are preliminary compatibility evidence; actual behavior, rendering, external APIs and target deployment need scoped acceptance in an authorized environment.
