# Editing and mix

Retain original takes and a non-destructive session or reproducible edit log. Use stable clip/timecode references and actual sequence order. Source time and timeline time diverge after cuts/speed changes;keep transcript and editorial decisions aligned.

Edit intelligibility,meaning,pacing and continuity. Noise/silence removal and crossfades can clip consonants or change turn-taking/context. Listen to relevant joins rather than relying only on waveform thresholds. Avoid accidentally repeating dialogue when concatenating segments.

Choose noise reduction,EQ,dynamics and limiting for the actual material. Aggressive processing can create artifacts. Balance voices and music through transitions,quiet speech,sponsors and endings. Fixed music-volume factors or compressor settings are not universal mix rules.

Use explicit working format/timebase and check resampling,channel layout,phase,sync and output compatibility. Loudness and true peak require a declared measurement method/tool;metadata or an extension is not measurement. A target number alone does not prove intelligibility or perceptual quality.

If editing/validation tools are unavailable,provide precise notes and mark execution unobserved. Do not install FFmpeg or call a paid voice service merely to make a planning task look rendered. Record actual versions,commands and errors when authorized processing runs.
