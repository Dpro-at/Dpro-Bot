# Animation production

## Scene and shot contract

Define audience,message/story,style,formats,duration,actual tool,assets and owner. Inspect approved references,brand and current scene/rig/timeline structure. Reuse suitable production conventions rather than requiring a single-file canvas or another renderer for every task. Keep rights and private reference media controlled.

Break the piece into shots with purpose,action,key poses,continuity,staging,camera,audio/text cues and timing. Keyframes describe element states through time;playing storyboard stills is not automatically the intended animation. Use a representative look frame or animatic when it resolves real uncertainty. Approval follows actual project/session authority,not a mandatory ritual for every reversible draft.

## Motion and implementation

Use timing/spacing,anticipation,weight,arcs,overlap,easing and holds deliberately for the chosen technique. Preserve pose readability,contact,continuity and audience attention. Do not animate every object merely because the tool permits it. Data/UI demonstrations need supported facts and actual product state rather than fabricated screens as proof.

Set explicit timebase/frame rate,scene boundaries,layout and asset dependencies. Procedural frames should behave predictably when rendered out of order;wall-clock or uncontrolled randomness can break reproducibility. This is a technique-specific requirement,not a reason to force hand-drawn or rigged work into code. Record fonts,assets,versions and dependencies needed by the recipient.

## Review the actual output

Inspect representative frames,holds,transitions and complete playback when available. Contact sheets reveal crop/continuity but do not prove temporal smoothness or audio sync. Check reading time,captions,safe areas,alpha/color/export behavior and actual delivery formats. Alternate aspect ratios can require recomposition,not blind cropping.

The existing optional timeline audit validates declared timing structure only. It does not inspect pixels,craft,claims or perceptual quality. A successful render/file-exists result is not visual acceptance. Record exactly which frame,playback,audio and mechanical checks ran and which remain unavailable.

## Handoff

When authorized/available deliver editable source,actual inspected export,dependency/license notes and a scoped review receipt. Otherwise deliver a complete production/shot packet without pretending it was rendered. Installation,paid generation,voice synthesis,private capture and publication follow actual authority. Audience response and real production acceptance remain separate from package preparation.
