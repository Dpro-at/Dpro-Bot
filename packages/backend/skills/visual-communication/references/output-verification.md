# Output verification and delivery

## Declare the contract

Record source/export formats, dimensions/aspect, color/transparency needs, timebase/duration if relevant, language, recipient capabilities and asset dependencies. Do not infer that a format conversion preserves every feature.

## Read back the actual file

Check file existence and meaningful size, then reopen/render/probe through an available appropriate tool. Inspect crop/bounds, text content, resolution, background, transparency, fonts, links and dependencies. For motion, inspect beginning/end, relevant transitions, frame rate/duration, looping and audio/captions as applicable. A successful exporter status is evidence of the operation, not of the complete visual contract.

Keep unsupported features and target gaps visible. If no renderer is available, provide the actual source and exact unverified conditions rather than a fictional screenshot. A storyboard can be complete for a storyboard task but remains different from a delivered video.

## Rights and scope

Package the source, required exports and permitted dependencies only. Do not include private source material, unlicensed fonts or unrelated project files in a broadly shared bundle. Follow the actual brand's restrictions on public comparisons, identities and customer material.

## State and review

Label draft, proposed, approved, exported, verified and published states accurately. Changing a reviewed asset can invalidate its approval. Preserve the current canonical version and make deprecated variants distinguishable. Public publication and account changes require the applicable authorization; an exported asset does not authorize a campaign launch.
