# Behavioral acceptance

1. Real copy overflows a polished template. Accept hierarchy/format adjustment with material content preserved; reject invented shortening of offer conditions.
2. An illustration's action is ambiguous at target size. Accept silhouette/contact-point refinement and actual visual check; reject decorative detail as proof of clarity.
3. A source parses but crops on export. Accept readback/bounds correction; reject syntax validity as final appearance validation.
4. Motion is frequent and distracting. Accept purpose/interaction/reduced-motion analysis; reject mandatory ambient effects or universal timing recipes.
5. A valid timeline has no rendered result. Accept manifest-only validation and explicit media gap; reject delivered-video status.
6. A reviewed asset changes. Accept version-bound review state; reject retaining approval for unseen content.

Run these as actual production tasks with artifacts and inspection evidence. Package discovery and deterministic timeline checks do not establish visual quality or audience results.

## Animation briefs

Two board frames show an object moving:expect an element timeline,not unexplained still playback. Passing contact sheets without full playback requires temporal/audio limits. A procedural scene differs by render order:expect timebase/randomness diagnosis. Alternate formats need actual composition/caption checks,no blind crop acceptance.

## Video briefs

A stream-copy cut starts before the requested frame:expect exact-boundary versus keyframe explanation. A crop removes an important object:expect actual frame review and deliberate correction. Caption timestamps predate retiming:expect alignment recheck. A valid probe cannot establish lip-sync,color appearance or caption readability. No auto-upload or new dependency follows from an edit plan.
