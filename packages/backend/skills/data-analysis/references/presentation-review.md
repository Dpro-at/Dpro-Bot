# Presentation review

Use a table for precise comparisons and a chart when shape or change is easier to understand visually. A figure should answer an actual question rather than decorate a report.

- Trends: show the relevant time interval and mark incomplete periods.
- Category comparisons: label units and use a consistent scale.
- Distributions: show spread and sample context, not only a mean.
- Relationships: distinguish association from causal interpretation.
- Forecasts/scenarios: separate observed data from modeled values and disclose assumptions.

Choose axes appropriate to the claim. Avoid an unexplained truncated scale that exaggerates a change, decorative3D or color distinctions that carry the only meaning. Include relevant denominators when rates are compared.

The headline should state a finding the data supports. Do not write an action title before the analysis has established it. Preserve limitations next to the figure when they affect interpretation.

For an exported artifact, inspect the actual file: labels, legends, clipping, resolution and whether it can be opened. Interactive output needs working controls and understandable defaults. A code snippet alone is not an exported chart.
