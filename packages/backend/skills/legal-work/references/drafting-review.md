# Drafting,synthesis and review

Match the deliverable to the request:short answer,issue register,contract edits,research memo or negotiation brief. Lead with the actual scoped conclusion,then support it with facts,source text and reasoning. A balanced answer considers material counterarguments and unknowns without padding the result with generic legal commentary.

Keep facts,allegations,assumptions,document terms,authority and judgment distinct. Link every material proposition to a retrieved source or exact document location. Do not let a confident summary conceal a missing schedule,uncertain jurisdiction or unverified subsequent treatment. If the answer depends on a fact,explain how the alternatives change it.

For editable documents preserve the original,version identity,numbering,cross-references and actual review mode. Inspect the output for unintended deletions,broken formatting or inconsistent defined terms. A conceptual before/after snippet is useful but is not tracked changes in a saved DOCX. Report the actual artifact and editing limits honestly.

Before delivery check decisive citations,quoted wording,party roles,dates,amounts,definitions and cross-document consistency. A mechanical citation check cannot establish correctness or current law. Use the responsible review path for interpretation,acceptance and formal reliance. Prepare concrete questions and alternatives so that review is actionable rather than an unbounded disclaimer.

State what was completed,actual evidence/validation,unresolved decisions and the next owner action. Do not send a draft,commit a negotiation position,file a document or represent an approval without applicable authority.
