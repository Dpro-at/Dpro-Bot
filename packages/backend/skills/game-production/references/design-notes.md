The game upstream provides much broader engine and discipline routing. This package offers a self-contained existing-project delivery workflow and explicit simulation, persistence, ownership and target-evidence boundaries. It does not include every engine API or substitute for those engine-specific resources. It preserves the user's engine rather than selecting a default engine from catalog coverage.

No matched model-task trial or quality superiority result is claimed. Acceptance briefs are unexecuted inputs. Parsing, resource integrity and native discovery are preliminary compatibility evidence; actual behavior, rendering, external APIs and target deployment need scoped acceptance in an authorized environment.
