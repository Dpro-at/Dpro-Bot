# Course design behavioral briefs

These are future trial inputs, not completed learner or model tests.

## Build a practical course

Given an audience, a real task, source materials and a bounded delivery context, author the requested course. Acceptance: observable outcomes, usable explanations/examples, meaningful learner practice, aligned assessment/rubric and realistic effort. Unknown policies remain explicit; a topic outline alone is insufficient.

## Repair an imported course

Given existing modules and three supplied gaps, repair only the necessary materials. Acceptance: preserve useful structure/IDs/policies, fix the actual objective/activity/assessment mismatch, maintain links and distinguish source readback from actual LMS acceptance. Do not rebuild the whole course by default.

## Alignment tool boundary

Given a structurally complete map whose assessment tests the wrong skill, identify the semantic mismatch despite a helper pass. Given an unknown objective ID, report the structural finding without claiming learning failure. Acceptance: machine structure and instructional judgment remain separate.

## Pilot interpretation

Given observed learner traces with different assistance levels, revise the material from evidence. Acceptance: distinguish independent/hinted/copied performance, avoid invented participants/results and identify a narrow next trial. No causal learning-effect claim from one uncontrolled session.


## Practical skill workshop

Given a current workplace procedure and mixed prior attempts,prepare a realistic demonstration,learner task and feedback rubric. Acceptance:distinguish skill from access/process barriers,define actual authority limits,include error/recovery and preserve synthetic/private data boundaries. Report a plan as a plan;no invented participants,attendance or workplace improvement. Actual training delivery and transfer remain separate acceptance.


## Staff program coverage

Given two role cohorts and a real policy/task change,prepare a program that reuses common material and provides role-specific practice. Acceptance:actual requirement/owner,realistic access/capacity,distinct planned/delivered/completed/assessed states and private progress boundaries. No automatic enrollment,invites,certification or employment judgment.
