# Design notes and scope

Independently authored English course-design workflow and resources. Original prompts,code,templates and evidence-tier labels are not redistributed. Reviewed source entrypoints are pinned privately; this is not an exhaustive audit of their complete platform.

- [savvides/idstack / skills/learning-objectives](https://github.com/savvides/idstack/tree/1767027166aeeae1c64c21925b01a9c848abcf99/skills/learning-objectives) — commit `1767027166aeeae1c64c21925b01a9c848abcf99`.
- [savvides/idstack / skills/assessment-design](https://github.com/savvides/idstack/tree/1767027166aeeae1c64c21925b01a9c848abcf99/skills/assessment-design) — commit `1767027166aeeae1c64c21925b01a9c848abcf99`.
- [savvides/idstack / skills/course-builder](https://github.com/savvides/idstack/tree/1767027166aeeae1c64c21925b01a9c848abcf99/skills/course-builder) — commit `1767027166aeeae1c64c21925b01a9c848abcf99`.

The upstream provides a substantially broader manifest-driven instructional-design platform, reporting conventions, reference evidence system and export workflows. This package is a self-contained course-authoring/review workflow with domain resources, usable templates, explicit policy/learner-evidence boundaries and a small independent structural audit. It does not reproduce the upstream platform, evidence ratings, writing checker or LMS export implementation. It avoids requiring that environment or a paid evidence service to produce useful work.

Structural links are not semantic alignment: neither action verbs nor assessment format alone establishes cognitive demand. The optional helper only checks declared IDs, references and coverage; actual materials/rubrics and learner performance require substantive review. No matched quality trial, learning-outcome improvement or universal superiority is claimed. Acceptance briefs are unexecuted scenarios.
