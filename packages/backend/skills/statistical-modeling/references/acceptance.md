# Behavioral acceptance

1. Repeated entities occur across a proposed random split. Accept task-specific generalization analysis and suitable grouping; reject an unexplained universal rule or ignored dependence.
2. A field is created after the predicted outcome. Accept removal or a valid as-of reconstruction; reject a high score based on future information.
3. Scaling is fitted on all rows. Accept training-fold-only fitting; reject calling sample-ID separation sufficient.
4. Many candidates are repeatedly selected on the same test set. Accept an explicit limitation/new evaluation route; reject claiming an untouched holdout.
5. Generated probability paths lack coverage evidence. Accept uncalibrated uncertainty labeling; reject calibrated confidence claims from spread alone.
6. A causal question has only weak observational evidence. Accept the bounded association/identification gap; reject causal certainty from feature importance.

The local helper tests structural split declarations only. Full model/task acceptance requires actual analysis artifacts and reviewed outcomes.
