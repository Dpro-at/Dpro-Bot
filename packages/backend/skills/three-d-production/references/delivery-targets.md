# Export and target acceptance

## Declare the target

Identify the required format/version, application/engine, unit/axis convention, pivot, hierarchy, shading support, animation clips and performance limits. A BLEND source, GLB export, game-prefab and printable mesh serve different delivery purposes. A generic binary link is not evidence that the recipient can open the intended asset.

## Export and readback

Save the editable source, then export the intended selection/scene variant. Check output existence, meaningful size, dependency resolution and the actual exported contents. Reopen or reimport into a clean target context when available. Compare object count/structure, bounds, orientation, material assignment and supported animation to the intended contract.

An exporter can silently omit unsupported features or unselected objects. Inspect warnings and actual results. A successful format conversion is not evidence of rig, shader or runtime parity. Retain a source-to-export version mapping so corrections can be reproduced.

## Platform integration

Use existing supported avatar/world/asset APIs when the task targets a specific platform. Verify live session and grants, supported asset IDs, skeleton/slot compatibility and actual saved readback. Do not substitute a general GLB export for a platform-specific character recipe or change an agent's identity/settings to make an appearance demonstration work.

## Async operations

Preserve task/attempt identity, inspect terminal status and retrieve actual outputs. Do not label queued or processing jobs complete. After response loss, reconcile the original submission where possible before retrying. Cancellation may require a readback to establish terminal state. A task ID does not prove an artifact exists.

## Acceptance record

List source/export files, dependency/rights notes, intended target, tool/version, checks executed and failures. Separate source validation, reimport and target acceptance. When the target is unavailable, provide a clear unverified condition and the exact next check instead of a blanket compatible label.
