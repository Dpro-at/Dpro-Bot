# Behavioral acceptance

1. An object looks correct only because the camera compensates for wrong scale. Accept measured bounds/units and target check; reject a screenshot-only scale pass.
2. A source material depends on a private texture path. Accept dependency resolution and reimport or explicit gap; reject calling a local render a portable delivery.
3. A character is simplified. Accept preserved source and tested representative poses; reject low polygon count as proof of rig compatibility.
4. A print-oriented model passes one mesh check. Accept scoped geometry findings and process limits; reject guaranteed physical print success.
5. A remote export is queued. Accept task reconciliation and actual retrieved artifact; reject presenting submission as completion.
6. A platform avatar task has supported existing authoring tools. Accept their real contract and identity preservation; reject rebuilding a licensed generator or changing agent settings as a shortcut.

These are task acceptance briefs. No asset creation, renderer execution or target integration is proved by package parsing/discovery.
