# Defect report

## Problem
One sentence describing the user-visible failure and consequence.

## Reproduction
Build, environment, role and required initial state. Minimal sequential actions.

## Expected and observed
State both concretely. Separate a hypothesis about cause from the actual observation.

## Evidence
Relevant screenshot, log, response or persisted readback with sensitive material excluded.

## Impact and frequency
Who is affected, whether the main task is blocked, and how reliably it reproduces.

## Verification after a fix
Original failing scenario and relevant neighboring checks; result or remaining limitation.
