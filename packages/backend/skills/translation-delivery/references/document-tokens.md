# Document and token constraints

Identify what must remain exact before translating. This can include code, placeholders, IDs, URLs, citations, formulae, product names, table keys and document anchors. Preserve their syntax and meaning under the actual format. A visible translation can be fluent while breaking the software or reference structure.

## Numbers and units

Check all amounts, dates, times, percentages, signs, ranges, units and comparison operators against the source. Distinguish a decimal separator from a thousands separator and an ambiguous date from an unambiguous one. Do not change units or currency because the target audience uses another system unless conversion is requested and correctly supported.

If localization is authorized, retain the original meaning and document the convention that matters. Precision, rounding and time zones can change practical meaning. A token-count match cannot prove that the same quantity is attached to the same object or condition;review the surrounding sentence.

## Markup and applications

Preserve required heading/list/table structure and links. For Markdown, check code fences, inline code and destination paths. For HTML/XML or localization resources, protect tags, attributes, escaping and placeholder names according to the project's format. Do not translate a machine-consumed key as though it were a display label.

Pluralization, gender and message interpolation may require the target platform's actual localization syntax. Inspect it rather than inventing a universal placeholder rule. Build/parse and rendered checks, when authorized and available, can validate mechanics;they do not prove semantic quality.

For technical documents, verify equation labels, cross-references, citation keys and protected scientific/technical identifiers. A term that looks like ordinary language may be an exact variable or account code. Preserve the brief's protected spans and record exceptions when a deliberate change is authorized.

## Coverage

For long files, use a source/target segment or section map. Mark missing, incomplete or intentionally excluded portions. Keep source and target revision references so a later source change does not make an old translation appear current. Avoid declaring a whole-document review from a sampled excerpt.

Use the permitted file tools and preserve original source files. Do not upload private documents to an external translation service without authorization. Shared glossary resources should contain approved reusable terminology, not accidental confidential passages.
