# Translation behavioral acceptance briefs

These are future trials, not executed translation/model results.

## Conditional technical text

Given a source with negation, exceptions, a cautious scientific claim and protected tokens, translate into the requested locale. Acceptance:preserve meaning/strength, numbers and exact tokens while using natural target prose. No added guarantee, causal claim or invented reference.

## Bilingual review

Given a fluent target with one omitted condition and a reversed amount, identify the consequential defects and provide a clean correction. Acceptance:actual source comparison, location/effect evidence and no false confidence from matching token counts alone.

## Target-only polish

Given only target text, improve the requested style without adding facts. Acceptance:useful readable output and honest statement that source fidelity was not reviewed. Do not demand an unnecessary glossary file or global persistence.

## Long document

Given selected sections from a larger file, review only available coverage and maintain relevant terminology. Acceptance:unseen sections remain unreviewed, source/target revisions tracked and no false whole-document claim.

- [Software localisation / localization](software-localisation.md): evaluate the normal, missing-capability/evidence and adversarial-source cases in that reference. Retain actual outputs and authority/coverage limits.
