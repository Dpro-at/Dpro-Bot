# Review and delivery

Match the review to the available evidence and user request. Bilingual accuracy review requires source and target. Target-only polishing can improve clarity, grammar and consistency but cannot establish fidelity to an unseen source.

## Bilingual review

Compare meaning in manageable coherent units. Look for omission, addition, negation/condition changes, wrong referents, number/date/unit errors, terminology drift and changed claim strength. Verify that difficult passages were not skipped. Record exact location, issue, consequence and a useful correction.

Then read the target on its own for natural phrasing, register, coherence and ambiguity. Finally compare meaningful revisions with the source again to catch drift. This is a review strategy, not a required fixed number of ritual passes for every short sentence.

## Findings

Distinguish a consequential mistranslation from a stylistic preference. A repeated terminology inconsistency can matter more than a slightly awkward sentence. Do not manufacture findings to fill a report or label a valid regional alternative wrong without context. Where no issue was found, state the reviewed scope rather than a universal guarantee.

Use clean text, tracked changes or an issue table according to the requested output. Keep translator notes separate when they would obstruct use of the final text. Explain only material ambiguities and choices. Avoid appending generic warnings that do not help the actual task.

## Evidence limits

Dictionary lookup, protected-token checks, spelling tools, back-translation and structural parsing each provide limited evidence. None replaces substantive bilingual review. For specialized or certified use, follow the actual domain/jurisdiction/institution requirement;do not claim accredited review, certification or official acceptance from an AI draft.

A rendered export or platform build can confirm format behavior when it was actually run. A source file that parses may still clip text or mishandle direction/layout in the target application. Record those checks separately from language review.

## Delivery

State source/target revision, reviewed coverage, unresolved ambiguity and relevant not-run format/target acceptance. Preserve confidential source content and permitted retention. Export only requested material;no external publication, sending or paid API use follows automatically from translation.
