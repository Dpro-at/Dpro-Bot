The sources provide broader entry-type examples, statement formats, variance and reconciliation catalogs. This package combines self-contained task modes with explicit entity/period/framework controls, source traceability, exact arithmetic scope and review/posting states. It avoids importing example thresholds, universal reversal/timing rules or mixed-framework assumptions. Current standard transitions require the entity's actual adoption/period. The optional helper checks declared arithmetic only;it does not certify accounting or reporting. No matched quality/audit/compliance claim.

Native parsing/discovery and deterministic fixtures are preliminary evidence. Actual provider tasks, domain review, live systems and delivered target acceptance remain separate. Behavioral briefs are future inputs, not executed results.
