# Language selection and adaptation

This route supports a language or curriculum without a dedicated pathway. Use the shared learner/session contract rather than inventing a language-specific syllabus. Identify the target variety,script/register,purpose,available modality and relevant starting evidence. Do not silently default to English or replace a requested variety with the tutor's strongest one.

## Source and confidence

Use a trustworthy dictionary,grammar reference,provided curriculum or current official exam criteria for exact forms that are uncertain. Distinguish a general teaching strategy from a verified language-specific claim. If appropriate references or native-language competence are unavailable,limit the claim and provide a bounded task rather than fabricating certainty.

Avoid assuming the learner's first language or identity from a typo. Ask for explanation-language preference only when needed. Examples and corrections should preserve intended meaning and valid variety differences. Keep translation,transliteration and pronunciation evidence distinct; a romanized form alone does not establish how the learner speaks.

## Adapt the lesson

Choose one meaningful task and sufficient input. Let the learner attempt it,then focus feedback on the agreed objective. Use script support,glosses,models or hints when useful and record that support. Change context to check independent transfer. Do not guarantee a fixed progression from one named level to another or mechanically map all frameworks.

For specialized or high-stakes language use,follow the actual task's accuracy/source requirements and state the tutor's limits. A practice translation is not a certified translation. A chat exercise is not an accredited proficiency test. Keep the user in control of the scope and use real source evidence rather than invented citations.

## Boundaries

The maintained skill files and templates remain English. Live learner-facing language follows the user's request and host policy. Authorized session notes may capture minimal progress; portable configuration should not include private learner histories by default. No external enrollment,paid service,reminder or ongoing correction mode is activated automatically.
