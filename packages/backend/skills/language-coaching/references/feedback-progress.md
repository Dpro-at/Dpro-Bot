# Feedback and progress

Use the learner's actual attempt. Preserve intended meaning before improving form. Distinguish required correction, contextual alternative, register choice and uncertain interpretation. Avoid inventing mistakes or praising unsupported competence because a template asks for a feedback block.

## Correction loop

Choose the most useful target for the agreed task. Briefly identify the issue, offer a clear model or hint and explain the pattern at an appropriate depth. Let the learner repair or use the pattern in a fresh context. Correcting every minor slip can interfere with a fluency objective; withholding all feedback can hide a repeated meaning-changing error. Choose deliberately.

Do not claim one expression is the only natural form when multiple forms or dialects are valid. State the register/variety of an alternative. If uncertain about the exact grammar, pronunciation or collocation, consult an appropriate reference or mark the uncertainty rather than teaching a confident invented rule.

## Progress evidence

Record objective, task, observed attempt, support provided and transfer result. Separate independent success, success after a hint, copied model and not observed. A high percentage on a repeated drill does not prove spontaneous use. A missed item may reflect attention or task ambiguity rather than loss of all prior knowledge.

Revisit useful material through retrieval in varied contexts. Select review timing and new-item load from the learner's availability, difficulty and actual performance rather than a universal daily quota. Do not promise a fixed number of hours to fluency or treat one scheduling algorithm as a substitute for effective practice.

## Memory and privacy

Keep short session notes only under the host's existing data policy and user authorization. Do not infer sensitive identity traits, store every personal story or write global profile files automatically. A portable settings export should contain the coaching configuration/templates, not private learner responses or a mistake history unless the user explicitly selects a suitable private-data export.

If reminders or a persistent review deck are unavailable, provide a usable plan without claiming it was scheduled. Distinguish a proposed next session from an active reminder. Keep updates scoped so corrections supersede stale notes rather than multiplying contradictory profiles.

## Reporting

End with the concrete skill practiced, useful evidence, remaining obstacle and one reasonable next attempt. Label informal level estimates, modality limits and unresolved forms. Formal tests and official ratings have their own administration requirements. Do not present an AI chat judgment as accredited assessment.
