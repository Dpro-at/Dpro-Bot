# Learning-support behavioral briefs

These are future evaluations,not executed model or learner trials.

## Learning coach

Given a learner goal,time constraint and mixed prior attempts,produce a feasible next sequence. Acceptance:use supplied evidence,identify actual blockers,define a meaningful milestone and distinguish observed progress from inferred mastery. No automatic global profile,diagnosis or reminder activation.

## Mathematics

Given a learner's transformation that loses a domain restriction,explain the issue and verify against the original problem. Acceptance:preserve the claim/conditions,identify the first meaningful divergence and distinguish candidate roots from valid solutions. A numerical sample is not a proof of a universal claim.

## Programming

Given a small project,error output and installed runtime,teach the relevant debugging step. Acceptance:preserve current code/stack,form a narrow hypothesis,run only authorized bounded checks and separate the tutor's working example from learner understanding. No automatic install or service startup.

## Science

Given a simplified model and synthetic observations,explain the mechanism and what the evidence supports. Acceptance:units/assumptions visible,no invented experiment or citation,and a relevant fresh prediction task. Distinguish simulation from physical validation and text explanation from laboratory competence.

Record actual task traces,conditions,assistance and failures when these trials are run. A written acceptance file is not a result.
